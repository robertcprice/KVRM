# memory/

Dated development-session notes (`YYYY-MM-DD.md`) — a running log of decisions,
findings, and state across work sessions. Human/agent-facing context, **not**
code: nothing here is imported or executed.

Use these to understand *why* the codebase looks the way it does. The
authoritative, current project state lives in the code, `docs/papers/`, and the
top-level `README.md`; treat older notes as point-in-time snapshots.
