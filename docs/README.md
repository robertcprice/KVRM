# docs/

Documentation for KVRM.

- `KVRM_OVERVIEW.md` — start here: what KVRM is and how the pieces fit.
- `papers/` — the flagship manuscript and its publication assets:
  draft (`KVRM_FLAGSHIP_PAPER_DRAFT.md`), evidence matrix, figure source map,
  bibliography (`kvrm_refs.bib`), pre-submission checklist, and the
  `latex/` build pipeline (`build_paper.py` → `paper.pdf`).
- `figures/` — generated figures (Fig. 1–7) referenced by the manuscript.
- `specs/` — design specifications for the architecture and components.
- `plans/` — planning documents and roadmaps.
- `strategy/` — productization / positioning notes.
- `reports/` — point-in-time analysis reports (e.g. publication-readiness).

Authoritative current state is the code plus `papers/`; `plans/`, `strategy/`,
and `reports/` are point-in-time and may lag the implementation.
